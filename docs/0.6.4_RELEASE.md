# LDFCL 0.6.4：界面流畅度优化

日期：2026-10-28（Asia/Hong_Kong）。以入门电脑、4GB 内存和 60 FPS 界面操作为优化目标，保留现有主页、Dock、左右实例布局和游戏功能。

## 默认行为

- 「启动器设置 → 外观与启动预设 → 界面性能」新增**流畅优先**（默认）与**视觉优先**。保存后应用；已有配置缺少此项时默认流畅优先，明确选择可持久化。
- 流畅优先保留主题、圆角、渐变、高光与阴影，省去面板 SVG 折射和模态背景模糊；上游 liquid-glass-react 仅在视觉优先时延迟加载，离屏/隐藏时卸载重型效果。面板尺寸变化合并为每帧最多一次全局通知。
- 首页和衣橱的 3D 皮肤静止时按需绘制；拖动、缩放、编辑、纹理和披风变化会刷新。默认不自动旋转，可手动开启；装饰旋转上限 60Hz，窗口失焦、隐藏或预览离屏时暂停。此上限不限制整个应用的界面帧率。
- 流畅优先的预览 DPR 上限 1，单次渲染跳过 FXAA 后处理；视觉优先 DPR 上限 1.5。切换或离开页面释放渲染资源。系统“减少动态效果”继续生效。
- Mod 与版本列表每页最多 50 项，提供中文总数、页码选择和搜索。Mod 可按中文、原名、文件名查找；所有项目仍可管理，末页删除后自动调整页码；版本外部切换时定位到选中项。
- 高频下载进度按任务保留最新状态，日志按实例保留最近 500 行，最多每 100ms 合并展示。日志页外只更新缓冲；下载实际线程、校验、取消和磁盘日志不受刷新频率影响。
- 资源、实例、衣橱、诊断与关于页面拆分加载。资源页首次访问才挂载，访问后切走保留现有搜索和选择；下载阶段的子任务使用单次索引，减少重复扫描。

## 测试方法与边界

完整自动测试、真实 WebGL 操作回归、版本/Mod 分页、事件和资源导航回归，以及真实 Windows 便携程序的前后对比见 [VALIDATION](../VALIDATION.md) 和发行资产。性能脚本为 `tests/ui-performance-smoke.cjs`，旧版基线使用未改动的 0.6.3 EXE，新版使用本次便携构建，两者均为 TEMP 合成目录与独立 Chromium 配置。

比较包含普通运行和 Chromium 渲染器 CPU 4×/6× 降速，记录 rAF 帧间隔、长任务、WebGL 绘制、布局/脚本时间、进程内存与 1000 Mod 场景。rAF 描述主线程/合成机会，不是物理显示器实际呈现帧的证明。CPU 降速不能替代 4GB 内存、老款核显或慢硬盘真机测试；安装、编译、首次页面加载及游戏本身不计入稳定界面采样。

目标硬件尚未完成真机验收，因此不承诺任意电脑在所有操作下瞬时最低 60 FPS。没有以关闭整个界面的动画或修改 Minecraft 图形/内存选项替代界面优化。

未操作真实 Microsoft 账号、在线皮肤或个人存档，未进行本轮真实 Minecraft 游玩；既有功能测试与这一边界分别记录。源码与 Windows x64 便携版一同保留。
