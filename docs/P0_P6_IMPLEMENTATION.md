## 核心与兼容性

`core/launcher.ts` 复用业务服务；Electron 仅提供窗口、IPC、系统浏览器、文件对话框、回收站和安全密钥能力。普通 Node 可以编译、加载、测试核心，CLI 无 Electron 依赖。构建前清除旧主进程业务输出，发行包不保留旧 `electron/services` 实现。

`launcher.json` / `accounts.json` 沿用既有结构及加密方式，仅增加可选配置。默认 `.minecraft` 与 `LDFCL-data` 在外部 EXE 旁，自定义游戏根登记及版本隔离继续保留。CLI 的两个列表不迁移、不写配置、不加载账号；其他高级命令初始化完整核心，会写配置并迁移实例，使用前关闭桌面启动器。没有实现同时运行两个可写宿主的统一锁协议。

## 清单、存储和恢复

```text
<程序目录>/
├── LDFCL-0.6.0-Windows-x64.exe
├── LDFCL-data/
│   ├── launcher.json / accounts.json
│   ├── store/sha256/<前两位>/<SHA256>
│   ├── store/manifests/
│   ├── diagnostics/
└── .minecraft/
    ├── assets/
    ├── libraries/
    └── versions/<版本目录>/
        ├── <版本目录>.json / .jar
        ├── instance.json
        ├── mods / config / saves / resourcepacks / shaderpacks
        └── .ldfcl/
            ├── manifest.json
            ├── migration-backups/
            ├── snapshots/
            ├── transactions/
            └── health/
```

原实例首次加载会生成声明与原件备份。JAR/ZIP 优先用只读硬链接，跨卷或不支持硬链接时复制并记录原因；配置、options、存档始终复制。硬链接不提供写时复制，外部强制去掉只读属性后原地写仍会损坏共享对象；读取 SHA 校验会拒绝坏内容，首次迁移的独立原件可以回退。Store 统计表示对象量与逻辑去重量，不是整块磁盘的真实节省量；迁移备份额外占盘，没有自动 GC。

单独 JSON 清单依赖当前 CAS；跨电脑应导出独立清单包，包含 `manifest.json + blobs/`。包还包含已存在的继承版本和库引用，包括没有下载地址的 Forge/NeoForge patched 库。目标根必须干净且版本目录名称一致，拒绝覆盖同名版本和有冲突的共享文件。Java、assets 和可公开下载的缺失运行依赖继续由启动准备补全，清单包不是完整离线游戏发行包。

快照覆盖 Mod、配置、资源包、光影、options、来源元数据与实例设置；世界、日志、截图、账号不回滚。启停、导入、更新、移除内容及保存实例设置前自动创建；启动写入选项前也保存。回滚先预览，再创建保护快照，恢复后同步启动器实例设置，防止下次启动覆盖已恢复的 options。详情见 [P1/P2 文档](P1_P2_STORAGE_AND_SNAPSHOTS.md)。

## 健康与崩溃诊断

健康扫描在本地检查所需 Java 主版本、架构、自定义 Java、前置 ID、低/高内存及最近 256 KiB 历史日志中的警告。报告含分数、严重性、建议及可自动修复标记。自动修复可恢复自动内存、清除无效自定义 Java、启用已经存在但禁用的必需前置，执行前快照并记录结果；缺少的新 Mod 仍通过原依赖下载安装流程补齐。

前置扫描验证 ID 存在性，不是完整的版本范围求解器。启动时仍执行现有账号验证、Java 选择/补齐和游戏文件准备；扫描评分本身不阻止所有带警告的游戏启动。

崩溃采集区分 stdout/stderr、跨 chunk UTF-8 与分行，实时保留 500 行，并采集本次新增/更新的 crash-reports、Java 致命错误文件及日志。正常退出和手动停止不生成假崩溃。规则覆盖内存、Java、缺失前置、重复 Mod、Mixin、图形/本地库等类型；可疑模组归因需要报告证据支持。未知报告明确表示证据不足。文件读取有大小和路径边界，报告及分享载荷会脱敏。

## P6 实现边界

- NeoForge 从官方 Maven 查询匹配版本、验证安装器 SHA-1，选择匹配 Java，在隔离阶段目录运行官方客户端安装器，并核对生成配置；整合包及下载界面支持 NeoForge。
- 镜像仅映射已知的公开游戏资源与库域名，认证端点保持官方。镜像失败回退官方；全局源存于设置，单任务切换在下一个文件/尝试生效，不会即时迁移已连接传输。
- `.part + .part.meta` 记录目标、URL、校验和及服务端验证器。续传使用 Range / If-Range；不支持 Range、验证器改变或部分内容不可信时重新下载，完成校验再发布。游戏文件及稳定内容缓存支持进程重启后重新请求同一下载继续；队列本身没有跨进程自动恢复任务列表。
- 暂停实际中止连接、保留可校验部分；继续恢复；取消删除部分文件，排队任务不会继续下载。已有最终文件在失败时保留，文件发布兼容 CAS 只读硬链接。
- 资源包编辑当前实例 `options.txt` 的 `resourcePacks` 与顺序；光影适配 Iris/Oculus/OptiFine 的真实配置，缺少渲染模组时提示。删除保留实例 `.trash`。不启动游戏也能启停，下一次进入游戏生效。
- 四档为流畅、均衡、画质、电影；设置可启用通用选项，实例可覆盖。主题支持浅色、深色和实时跟随系统，保留现有玻璃组件与布局。
