# Qt runtime

The Windows package dynamically links to the Qt 6.8.3 runtime under the GNU Lesser General Public License version 3. Qt's shared libraries and plugins can be replaced with compatible builds. The license texts are distributed alongside this notice.

Corresponding Qt source is available for [Qt Base](https://github.com/qt/qtbase/tree/v6.8.3) and [Qt Declarative](https://github.com/qt/qtdeclarative/tree/v6.8.3). The full Qt source archives are available from the [Qt 6.8.3 release directory](https://download.qt.io/archive/qt/6.8/6.8.3/single/).
