# LDFCL 0.7.0 现代工作区重构

日期：2026-11-15。基于已发布 v0.6.5，源码分支 `codex/modern-workspace`。本版为本地可运行构建，尚未作为 GitHub Latest 发布。

## 结构

- `src/App.tsx` 仅负责路由和功能组装，各页面延迟加载；首页的 3D 依赖从主入口分离。
- `src/hooks/useLauncher.ts` 统一状态、IPC、账号/游戏事件、日志与任务合并；核心仍使用 `@ldfcl/core`，Electron 宿主和 CLI 共用业务实现。
- `src/app/navigation.ts` 定义功能树；侧栏、功能搜索、设置分类共用入口定义。
- `src/pages/` 分离首页、账号、下载、全局设置；专属业务组件继续放在 `src/components/`。
- `src/ui/` 的 Modal、Tabs、PageTitle 负责通用交互。原生 dialog 提供背景不可交互、焦点限制、Esc 和关闭后焦点恢复；资源、实例、下载和角色标签支持方向键切换。
- 基础控件、语义配色、壳布局、首页、表单、材质及动效分文件维护；移除原 App 中重复页面/账号/设置定义及旧 Dock/首页/主题覆盖规则。
- 全局设置草稿跨分类、跨页面保留；后台状态刷新合并未编辑字段，保存仅提交变化字段，避免覆盖后台刚更新的设置。

## 视觉与性能

默认 1120×760，960×640 自动使用紧凑图标侧栏；页面允许垂直滚动。浅深色采用同一套语义色变量。默认高不透明度轻量材质，视觉优先仍可启用 liquid-glass-react。

页面入场、弹窗、标签指示器和按压反馈使用短时 opacity/transform 动画。无常驻背景动画，不提前给所有卡片分配合成层；访问过的资源页保持搜索/目标状态，隐藏时停止动画，3D 角色离屏停止。版本与 Mod 每页最多 50 行，快速版本选择每次加载 40 项；任务/日志批量更新沿用已有节流。

`interfaceMotion` 存储 `system`、`full`、`reduced`；旧配置默认跟随系统，无效旧值安全回退。系统减少动态效果始终优先，并同步暂停 3D 装饰旋转。设置对下次打开程序仍有效。

## 保留的数据与业务

账号与配置仍在外部 EXE 旁 `LDFCL-data`；默认 `.minecraft` 同样位于程序旁。任意已登记游戏目录、共享 assets/libraries、`versions/<实例文件夹>` 中的 Mod/存档/options.txt 隔离继续使用原来的核心实现。此次没有重新迁移游戏文件。

保留微软设备代码授权、下载队列与校验、Java 补齐、内存分配、旧实例关联修复、中文选项默认值、快照与清单重建、GitHub 更新及唯一桌面快捷方式。新交互验证通过合成数据驱动真实界面；不把这些检查等同于真实账号授权、网络安装或长期游戏验证。

具体检查及成品审核结果见根目录 `VALIDATION.md` 和本地 `release/0.7.0/verification.json`。60 FPS 是优化目标；受控 CPU 降速与按需绘制检查不能保证所有 4GB / 老核显电脑上的瞬时最低帧率。
