# LDFCL 0.6.5：更新确认、桌面快捷方式与顶部提示

日期：2026-11-04（Asia/Hong_Kong）。保留 0.6.4 的界面性能模式、游戏目录、账号和下载等功能。

## 更新流程

旧流程在 PowerShell 进程创建后立即退出启动器，只能确认 `Process.Start` 返回，无法确认更新助手已执行或新版界面正常。本机只读核对发现完整下载缓存和助手脚本，但没有结果日志；这不足以确定当时的具体失败原因。

新版在更新助手确认就绪后才退出。事务使用独立 JSON 文件传递路径和参数；等待 Electron、便携外壳和 EXE 文件锁释放，重新核对 SHA-256 后原位替换。新版必须完成核心初始化、实际挂载界面并回传本次事务的就绪确认，助手再检查进程存活；仅创建进程不再算更新成功。

助手无法启动时保留当前界面并显示错误。替换后新版未正常就绪时尝试恢复旧 EXE 并重新打开，保留备份、日志与结果；下一次打开可查看上次失败或回退记录。失败记录不会被启动时的自动检查立即覆盖。原来的 GitHub 来源限制、下载校验及游戏/下载进行时禁止重启规则保留。

## 桌面快捷方式

Windows 便携版首次打开时，没有快捷方式会创建固定的 **LDFCL.lnk**。目标、工作目录和图标都使用外部 EXE，更新继续原位替换，不指向临时解压目录，也不创建含版本号的新图标。已有正确链接不重复写入。

只清理能确认属于同一安装的旧重复链接，支持 Windows 中英文“发送到桌面”命名与默认 EXE 图标。其他程序、其他安装、带自定义参数或其他图标/工作目录的链接保留；固定名称被其他项目占用时也保留原文件。桌面路径来自 Windows/Electron，支持重定向和 OneDrive，不自行拼接用户目录。

## 更新提示

主界面使用标题栏下方的顶部弹出卡片，脱离页面滚动与裁剪层。正文可单独滚动，关闭、进度和操作按钮保持可见；支持明暗主题、1120×760 与 960×640 窗口、Escape 关闭，不自动抢焦点。设置页继续保留更新卡片。

关闭同一状态后不反复弹出，新版本、下载完成或新的失败事务可再次提示。后台单纯网络检查失败显示在设置页。首次状态快照不会覆盖已经到达的新更新事件。

## 验证和使用

验证包括 Windows 原生 `.lnk` 临时桌面测试、更新助手的成功/失败/回退与特殊路径测试、顶部弹窗浏览器回归，以及最终便携 EXE 的启动、更新状态和恢复 smoke。真实跨版本替换仍以隔离的助手夹具覆盖；没有对 GitHub 发行文件执行实际下载和覆盖。准确数量、包与源码摘要、独立重建结果见发行资产 `VALIDATION-0.6.5.md`、`verification.json` 和 `SHA256SUMS-0.6.5.txt`。

测试使用 TEMP 合成安装和数据，不修改个人桌面链接、真实账号、游戏文件或 `C:\pcl` 安装。没有进行本轮 Microsoft 账号授权、在线外观或 Minecraft 游玩。

如果旧版更新助手已经无法运行，请先手动下载本版，将 EXE 放回原安装位置并保持原文件名，例如 `C:\pcl\LDFCL.exe`，保留旁边的 `LDFCL-data` 和 `.minecraft`。启动本版后会维护同一个桌面快捷方式，后续更新使用新的确认流程。
