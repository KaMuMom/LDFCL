## 改动范围

0.5.0 的改动集中于 React 界面、视觉适配层、样式与依赖及来源文档。账号协议、游戏安装与启动、隔离目录、下载调度、Java、Mod 依赖解析和更新、皮肤库及设置持久化沿用现有服务。组件中的 IPC 调用、异步状态、错误重试、业务选择、键盘操作和原有测试选择器继续保留。

| ---------------------------- | ------------------------------------------------------------------------------------ |

| 账号、设置、任务、日志与关于 | 统一表单、状态、列表、按钮和对话框的视觉层级，保留现有功能入口                       |

视觉采用正文 `#172c47`、强调色 `#3569e8`，配合轻边框、柔阴影、浅色玻璃表面和清晰内容层。界面仍使用 Electron / Chromium，皮肤和游戏的 3D 渲染继续由原有组件负责。

## GlassBackdrop 与语义容器

[src/ui/Glass.tsx](../src/ui/Glass.tsx) 提供两个应用适配组件：

- `GlassBackdrop` 渲染真实的上游 `LiquidGlass`，放在容器内的绝对定位装饰层；设置 `aria-hidden`、`inert` 和 `pointer-events: none`，避免参与键盘焦点、可访问内容和点击命中。
- `GlassSurface` 保留 `section`、`article`、`form`、`div`、`aside` 等原有语义标签及 HTML 属性，在其中加入装饰层，业务 children 保持为清晰、可选择的独立内容。原生 dialog 保留原标签，并在内部放置 `GlassBackdrop`。

上游演示组件包含居中定位、尺寸、文字和鼠标形变行为。应用样式只在 `.glass-backdrop` 范围内适配其渲染结构，把效果填满容器；正文、表单和可交互元素继续由应用布局控制。适配层观察容器尺寸变化，合并调度尺寸刷新，以配合列表切换、窗口缩放和弹窗内容变化。弹窗自身滚动时，装饰层跟随滚动偏移保持覆盖视口；集成检查确认不增加内容滚动高度。

本版使用上游公开的 **`mode="standard"`** 折射模式，`elasticity={0}`，按容器圆角传入 `cornerRadius` 并使用零内部 padding。折射、霜化、饱和度与色散由上游组件渲染，正文层使用应用的字体、对比度和间距。上游 README 提示 Safari / Firefox 对折射支持不完整；当前发行目标为 Electron / Chromium。

## 旧视觉层清理

本轮以一套设计系统替换旧样式堆叠：

- 重写全局 `src/style.css`，取消旧 `src/mica.css` 叠加入口及文件；历史 Mica 视觉不再作为当前 renderer 的样式基础。
- 清理旧 landscape 背景及其引用，改用应用内的浅色渐变与玻璃表面；不再依赖该旧背景素材。
- 资源、实例、账号、皮肤等页面各自保留必要布局样式，删除旧内联配色、旧外观覆盖和重复规则。
- 保留仍用于功能和测试的类名、aria 标签及控件语义；类名保留不代表继续加载旧视觉样式。

早期 TryLiquidGlass-WinUI3 的视觉参考和 Mica 实现记载保留在 [CREDITS.md](../CREDITS.md) 与历史验证记录中，供来源核对。
