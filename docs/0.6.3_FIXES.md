# LDFCL 0.6.3 问题修复

这是此前本地开发版本的历史记录。以下修复现已纳入 0.6.2 发行版本，当前内容见 [0.6.2 发行说明](0.6.2_RELEASE.md)。开发基线为 GitHub v0.6.2-beta.1 / 814da11f5499c211919e0df026b1b74d4bd9e1c7，保留原有账号、独立版本目录、Mod 和资源功能。

## beta.2 旧实例提示

- 缺少旧实例版本关联时显示“版本关联信息待确认，旧实例文件已保留”，移除要求重装的措辞。
- 设置页以信息图标和淡色面板展示“旧实例兼容提示”，默认收起，展开后逐项查看，长列表可滚动；目录切换通知仅显示提示条数。
- 兼容提示与真实目录错误分别传递；成功切换后清理上一个目录的提示，切换失败保留原目录的提示。
- 本次仅更新提示呈现，不自动修复版本关联，不改动旧实例迁移规则或个人游戏文件。

## 启动提示与空 Mod

- 原版、Fabric/Forge/Quilt/NeoForge 可以没有 Mod；缺少 mods 文件夹和空列表均正常。
- 历史日志中的 WARN/ERROR/FATAL 仅作为历史信息展示，不降低当前健康评分，不冒充本次启动失败。当前进程失败仍按本次日志、退出状态和诊断报告呈现。
- 进程创建成功后，保存最近启动记录或最小化窗口失败会返回单独提示，不再把已经启动的游戏显示为启动失败。可选健康报告保存失败也不会阻止启动；游戏选项、快照与真实进程错误仍按原有规则处理。
- 运行状态由进程事件维护，界面刷新时同步，避免已经退出的进程被迟到的启动响应重新标记为运行中。

原始用户提示尚未在同一真实 Minecraft 环境复现。代码审查与受控复现确认了历史警告分级过宽、启动后记录保存失败两条误报路径，修复并覆盖相关场景；不把空 Mod 本身认定为已证实根因。

## Windows Unicode 路径（Issue #6）

本机中文代码页下，Java 8/17/21 的原生启动器会把 emoji 参数和 classpath 转为问号，单独设置 -Dfile.encoding=UTF-8 无效。兼容启动采用项目原创 Java 8 引导组件，使用标准系统 ClassLoader 与清单 classpath，避免自定义 ClassLoader 改变加载器行为。

- 为 JVM 启动参数、工作目录和原生运行库建立每次运行独立的 ASCII 路径别名；游戏数据保留在原位置，别名不改变 versions/<实例目录> 的隔离结构。
- 非路径参数通过匿名标准输入管道以 UTF-8 传入，令牌不写入临时参数文件。
- 长 classpath 使用引导 JAR 清单，避免超过 Windows 命令行长度。
- 进程结束或启动失败后只清理本次创建的文件和链接，不递归删除链接目标。
- Java 源码保留在 build/java/LaunchBootstrap.java；scripts/build-java-bootstrap.cjs 可重建校验的内嵌字节码，用户运行发行版无需安装 javac。

真实 JVM 探针覆盖 Java 8/17/21、emoji、引号、反斜杠、系统 ClassLoader、Java agent、原生 DLL、长 classpath、真实目录写入与清理。另使用本地合成客户端 JAR、原版/Fabric 元数据走真实 GameService.launch；该测试不等同于真实 Minecraft/Fabric 游玩。Java 25 未实测。

## 下载信息（Issue #3、#5）

- Minecraft 安装开始即登记版本解析、加载器、本体与运行库、原生库、游戏资源、日志配置和保存实例阶段；未知阶段显示待解析，不虚构文件总量或整体百分比。
- Mod 及必需前置、整合包等在解析后展示已知文件清单、资源名、目标实例和当前文件。
- 按字节显示下载量与百分比，文件完成数量单独标注；未知大小明确说明。完成文件数比例不再与字节百分比混为同一口径。
- 计划与子下载分组显示，文件清单分页，任务事件仅携带有界活动文件，避免一次推送数千条完整记录。
- 保留并验证暂停、继续、取消、并发、镜像切换、重试和哈希校验。

## 默认皮肤与玻璃材质（Issue #1、#2）

- 首页和皮肤页共用项目原创默认贴图，补齐头顶、侧面和背部头发 UV，避免旋转后出现缺发。
- 首页用播放/暂停表示自动旋转，刷新外观使用独立按钮；异步刷新按请求代次处理，旧账号结果不会覆盖新账号。
- 玻璃装饰层限制在自身裁剪与绘制边界内，去除上游演示控件的额外兄弟阴影层，保留原有真实折射组件、布局、主题和许可证。
- 专项界面回归覆盖浅/深色及默认/紧凑窗口，检查悬停、按压、拖离和切页。

## 失效目录（Issue #7）

- 失效条目标记为不可用，停用打开/使用操作，给出重新定位或移除登记选项。
- 重新定位仅更新登记位置，保留实例 ID、当前选择和用户文件，不复制游戏数据、不重建旧路径；重复目标和取消选择不改配置。
- 登记过的默认目录被删除后，重启也不会静默重建；用户可明确点击创建默认目录。首次启动仍自动在程序旁创建默认 .minecraft。
- 底层实例准备也拒绝重新创建缺失的登记根；兼容旧布局时，只允许在仍然存在的旧数据根内创建所需的 minecraft 子目录。
