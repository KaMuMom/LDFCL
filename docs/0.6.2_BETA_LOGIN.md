# 0.6.2-beta.1：微软登录配置与授权码

基于 0.6.1 的启动修复版本；保留 P0–P6 既有功能。本地规则诊断继续可用。

## 应用 ID 的保存与展示

- 桌面宿主注入 Electron `safeStorage`，Windows 使用当前系统用户的凭据保护能力。核心不内置加密密钥，也不依赖 Electron。
- Microsoft 应用 Client ID 通过本机加密后存入程序旁 `LDFCL-data/launcher.json`；旧版明文配置会在加密可用时自动迁移。配置写入使用临时文件与替换，失败保留原配置。
- IPC 的公开设置只包含空的 `microsoftClientId` 和是否配置、存储状态。界面输入框为密码类型且不回填旧值；留空沿用配置，输入新值则替换。保存其它通用设置不会清除 ID。
- 加密不可用时不将新值写为明文；旧版配置迁移会等待系统加密恢复，主界面仍可显示。异用户或损坏密文不覆盖，界面提示重新配置。只读 CLI 不迁移或写文件。
- Client ID 是 OAuth 公共客户端标识。这里保护本机保存和界面展示；微软登录请求必须使用原值，无法保证对调试、进程内存或流量检查者隐藏。没有添加客户端密钥，也没有借用其它启动器的应用身份。
- 本机密文与系统用户绑定。整体移动到其它电脑或 Windows 用户后可能需要重新输入 ID、重新登录。

## 自动复制授权码

1. 读取本机配置并向微软请求设备授权。
2. 核对请求仍有效且未取消，在主进程同步复制公开的 `user_code`。
3. 打开系统浏览器的微软授权页面，用户直接粘贴并完成登录。

每次有效请求只自动复制一次。取消、关闭或被替代的旧请求不能在响应晚到时覆盖剪贴板。私有 `device_code` 与账号令牌不会复制到剪贴板，也不会通过这次改动发送给渲染进程。

剪贴板写入失败会保留登录流程，页面明确显示手动复制提示。保留“复制授权码”和重新打开微软页面的按钮；轮询重试不会再次覆盖剪贴板。
