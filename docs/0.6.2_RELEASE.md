# LDFCL 0.6.2

Windows x64 便携发行版，GitHub 标签为 `v0.6.2`，以非预发布版本设为 Latest。源码、EXE、SHA-256 和最终验证记录随发行提供。

## 变化

- 使用用户指定的透明像素图标，保留原始素材；PNG、窗口图标与多尺寸 Windows ICO 同步更新。
- 没有加载器或没有 Mod 的实例可以正常准备；历史日志和启动后记录保存失败不会冒充本次游戏启动失败，进程状态随实际事件同步。
- 改进 Windows 中文、emoji 及长 classpath 的 Java 启动兼容；保留 Java 引导源码，令牌通过匿名管道传递。
- 下载显示阶段、目标实例、文件清单、字节进度和未知总量，保留暂停、继续、取消与镜像切换。
- 统一默认皮肤，调整旋转及刷新控件，修复玻璃组件的阴影溢出。
- 已移动或删除的游戏目录可重新定位，不会静默重建旧路径；保留实例身份和用户文件。
- 旧实例版本关联不明确时显示默认收起的兼容提示，逐项说明旧文件已保留，真正的目录错误独立显示。

原有账号、皮肤库、版本隔离、Mod 和资源管理继续保留。升级时先退出旧启动器，将新 EXE 放入原启动器目录，继续使用旁边的 `LDFCL-data` 与 `.minecraft`。

## 验证与边界

本版构建、自动测试、成品和源码归档检查结果见随发行附带的 `VALIDATION-0.6.2.md`、`verification.json` 与 `SHA256SUMS-0.6.2.txt`。开发阶段的详细实现和验证记录保留在 [问题修复记录](0.6.3_FIXES.md) 与 [VALIDATION](../VALIDATION.md)。

旧实例迁移提示的更新只涉及信息呈现，未自动修复不明确的版本关联。Microsoft 登录仍需要获准的应用 Client ID；受控测试不等同于真实账号授权或真实 Minecraft/加载器游玩。程序没有 Authenticode 签名。
