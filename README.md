# LDFCL

LDFCL 是一个用 C++17 和 Qt Quick 编写的 Minecraft Java 版启动器。桌面界面使用 EvolveUI 组件。

- 浏览本地已安装的 Minecraft 版本，可直接使用 PCL 或 HMCL 的游戏目录。
- 为所选版本指定本机 Java。
- 使用离线身份 `Player` 启动游戏。

Windows 安装程序支持创建空游戏目录，也支持沿用现有目录。游戏客户端、资源和依赖需预先安装。桌面版和命令行版共用同一套启动核心。
