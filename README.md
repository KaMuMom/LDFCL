# LDFCL

LDFCL 是一个用 Rust 编写的 Minecraft Java 版启动器，桌面界面使用 GPUI。

- 浏览本地已安装的 Minecraft 版本，可沿用 PCL 或 HMCL 的游戏目录和版本隔离设置。
- 自动匹配游戏所需的 Java，也可以从本机 Java 列表手动选择。
- 使用离线身份 `Player` 启动游戏。

Windows 安装程序提供简体中文和英文。启动器从安装目录启动并在其中保存配置和缓存。游戏客户端、资源和依赖需预先安装。桌面版与命令行版共用启动核心。
